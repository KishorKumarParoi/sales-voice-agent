- **Production URL**: [https://sales.kishor.tech](https://sales.kishor.tech)
- **Role**: Autonomous SaaS product advisor and pricing sales agent from Nimbus Voice Agent.
- **Capabilities**: Annual Savings Calculator, Cart Checkout & Quotes
- **Sub-400ms Voice Pipeline**: ASR -> OpenAI GPT-4o-mini reasoning -> ElevenLabs Turbo v2.5 TTS.
